# SXT-026a — voice-leaf scope extension: parameterized voice class (issue #48)

**Outcome:** the landed SXT-022 voice leaf is extended, by parameterization
only (no new arithmetic), to a declared class that contains the ORIGINAL
voice graph of `Rozzer/Bells/Hell's Bells.fxp` — the unique compiled corpus
preset whose legal FX (Reverb 1 @ send2) survives every upstream gate. The
SXT-025 integrated path has been re-run with this ORIGINAL voice stage
replacing the engine-dry-bus substitution: the configuration is no longer
*adapted* at the voice stage. Model-vs-reference agreement on the extended
slice **does not meet the [PROPOSED] budgets** (dry and, propagated through
Reverb 1, wet); those numbers are recorded as a bounded finding and routed to
SXT-013/#12. Nothing here weakens the wet-preset gate, and no support claim
is made.

Claim discipline (AGENTS.md): this record establishes (1) RTL==frozen-model
EXACT (integer equality) and (2) model-vs-pinned-engine agreement *numbers*.
It establishes no fidelity verdict (budgets are proposals, PENDING-FREEZE,
owned by #12), no preset-quality claim (no listening record exists), and no
hardware/FPGA claim.

## 1. Frozen class (`model/voice/README.md`, "SXT-026a extension")

Superset of the SXT-022 v1 class; v1 arithmetic unchanged; parameterization
carried by schema-2 input sidecars (`extract_inputs_v2.py`, `InputsV2`),
fail-closed (`Refuse` → exit 2):

* v1 structural bounds (single scene A, poly, serial-1, ws/lowcut off,
  o1-only mixer, unit 2 Off, drift 0, pan 0, pfg 0, vca_velsense 0, Warm,
  digital envelopes, osc1 keytrack on / pitch 0 / unison 1 / retrigger).
* Osc 1: Classic (v1) **or Sine** legacy path (`sine_shape(mode)==0`,
  `sine_FMmode==0`, unison 1, retrigger; lowcut/highcut biquads modeled;
  `sine_feedback` inert in the legacy path — never read).
* Filter unit 1: LP 12 dB **or LP 24 dB**, subtype Driven (IIR24CFCquad:
  two coupled-form sections, shared C[0..7], one clipgain from y2).
* FM routing: `fm_switch` 0 or 2 (`fm_3to2to1`); muted Sine oscs 2/3 run as
  FM sources; depth = `db_to_linear(fm_depth)`, constant per fixture (CC
  events on Sine presets refused — the class's modwheel scene route targets
  FM Depth).
* Velocity/keytrack route vocabulary (voice) and modwheel→{fu1 cutoff, fu1
  reso, FM depth} (scene); keytrack source = `(pitch − ktR)/12` with the
  declared 1-control-pass lag.
* Scene octave `oct` → `pitch = key + 12·oct`; rendered pitch ∈ [24,148].
* Scene width: structurally inert at serial-1 (engine reads width only for
  fc_stereo/fc_wide); gate dropped from tier-4; oracle A/B probe below.

Numeric choices are frozen in `model/voice/README.md` (Q-formats, round-half-up
discipline, exact big-int fastsin/fastcos evaluation, declared audio-rate
division deviation from A-ALU-2 recorded for SXT-016).

## 3. RTL-vs-model EXACT (integer equality; `tools/compare_rtl_model.py`)

All runs: `iverilog -g2012` on the box clone at the pinned commit
(`canonical-chain-commit.txt`), same-block-schedule stimulus (`rtl/*.hex`)
generated by `model/voice/run_model.py` from the committed sequence.

* **Canonical (Hell's Bells, `model/integration/sequences/sxt025-accept-v1`,
  26,250 blocks / 840,000 samples):** `exactness-canonical-bells.json` —
  verdict **PASS, 0 mismatches**: 23,255 checkpoints, 674,395 fields,
  1,488,320 oscillator-output samples, 840,000 mono samples, integer
  equality throughout, executed at the committed HEAD tb.
* **Smoke (Bells, `fixtures/sequences/leaf48-smoke-bells-v1`, 122 blocks):**
  PASS, 0 mismatches (193 checkpoints), reproduced at HEAD.
* **Finding F-48c (defect found and fixed by the canonical run):** the first
  canonical execution hit X-poisoned mono output from block 12,963 to the
  end of the render. Root cause: the testbench's ctrl-stream array was sized
  by a stale magic constant (4,200,001 words) while the canonical stimulus
  carries 26,250 × 324 = 8,505,000 words — the stream read ran out of bounds
  at exactly block 12,963 (ci = 4,200,012), and the old desync guard's
  `!== 32'hxxxxxxxx` test silently *passed* on the out-of-bounds X, letting
  X flood the bus through the X-branch of the slot-active `if`. The fix
  (this branch) sizes the array from a declared MAX_BLOCKS capacity, checks
  the stimulus length against it fail-closed at load, and converts every
  X-read in the control stream into a hard `$fatal`. Neither the smoke
  fixture nor any earlier artifact could have caught this; the canonical
  acceptance case did exactly what it exists for. The canonical result
  reported here is the POST-FIX rerun at HEAD; the model render feeding the
  stimulus is byte-identical pre/post fix (render re-verified at HEAD).
* **v1 regression (Attacky via schema-2 sidecar `attacky_inputs_v2.json`):**
  model renders byte-identical to the committed SXT-022 artifacts on all
  three canonical sequences (`seq-notes-repeated-v1`, `seq-notes-coverage-v1`,
  `seq-modwheel-v1`); RTL smoke PASS (`exactness-v1-attacky-smoke.json`).
  This is the "class-v1 fixtures render bit-identically" check.

  over an uncommitted stimulus, `exactness-bells-canon.json`,
  `reference-*/smoke-*` oracle renders) were **superseded**: their canonical

  cited. F-48c also means the oracle reference/model wavs for the canonical

  model/oracle outputs (unaffected by tb sizing) and the HEAD model render
  is byte-identical (re-verified), so the audio comparisons stand.

  it); the frozen class models the live behavior (§6).
* fastsin/fastcos exact big-int evaluation declares an audio-rate division
  deviation from A-ALU-2 (README); recorded for SXT-016 costing.
* The two comparators disagree in RMS-row comparison direction
  (`compare_audio_reference.py` uses ≥, `compare_integration.py` uses ≤);
  both are committed SXT-022/SXT-025 semantics, used as-landed and reported
  as-landed here. Reconciling them is a #12 freeze decision, not this leaf's.
