WHY THIS FILE EXISTS
========================================================================

This PR is the designated one-time regeneration of the sxt-024
`comparison/*.json` and `negative-controls/*.json` records (#100 deferred it,
#108 deferred it, and #111 states outright that "the sxt-023 and sxt-024 leaf
records themselves are not rewritten"). Defect (2) of issue #112 is "fields
added to the tool after those records were committed" -- so a regeneration
that is itself missing fields the tool on `main` writes would recreate the
very defect it is closing.

Between this branch's base (8ade1d1) and `main` (f59d8ba), `main` gained
2f086e1 (#111, "windowed decay-curve tail-shape leg"), which added
`tail_rms_rel_ok`, `tail_decay_curve` and `tail_decay_curve_ok` to
`tail_check` / `tail_check_lr` in the shared/stereo wet-path tail gate.
`tools/compare_reverb_model.py` writes `car.stereo_tail_gate`'s return
verbatim into `res["tail_gate"]`, so the sxt-024 records inherit those fields
without any change to this tool.

The records were therefore regenerated a SECOND time, on the merged tree, and
this file records that run. `after/` in this artifact directory is the result
of the second run and is byte-identical to what is committed in
`reports/sxt-024/comparison/` and `reports/sxt-024/negative-controls/`.
